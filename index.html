OpenClaw Drive Archive

This is a personal, locally operated archive tool. It uses Google OAuth to save articles selected by the account owner as Markdown files in the owner's Google Drive. It also reads archived files and their metadata to verify uploads and, when requested, create article-analysis notes in the owner's Drive.

The tool requests Google Drive access because its existing archive contains files it needs to read and update. It is not offered as a public service. This website does not collect article content or OAuth credentials.
